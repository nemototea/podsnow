PORTRAIT PODCAST STUDIO

情報構造とナビゲーションの整理

「録音」「編集」「詳細」「音の仕上げ」「書き出し」は別々の機能ではなく、ひとつの Episode の中の工程である、という前提で階層を決めています。ユーザーが覚える階層は Show → Episode → 工程 の3段だけです。

6 — 決めたこと / 未決
決めたこと
録音画面は独立させず Editor に統合する
状態（Draft / Ready / Exported）はアプリが自動判定
工程の入口は Episode トップに集約し、Editor の ⋮ からも到達可
破壊的操作は確認ダイアログを出さず Undo で守る
アプリ全般設定と番組設定を分ける
相談したいこと
複数 Show を持てるようにするか（今は1番組前提）
Episode トップを省略して Home から Editor 直行にするか
Edit History 画面をいつ出すか（MVP では非搭載）
テンプレートの編集画面を Show 設定に置くか
