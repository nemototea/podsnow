# 実機チェックリスト（Issue #51）

自動テストで検証できない項目。各項目は **iOS / Android の両方**で、結果（日付・端末・OS・合否・メモ）を下の表に残す。
AUDIO_DESIGN.md §11 の S-1〜S-10 に対応。

## 前提

- Development Build（`npm run ios` / `npm run android`）。iOS は Xcode 26 以上が必要（Expo SDK 57）。
- マイク権限・通知権限（Android 13+）を許可済み。
- 空き容量 1 GB 以上。

## A. 録音の基本

| # | 手順 | 期待 |
|---|---|---|
| A-1 | Home → ＋ → 録音ボタン → 30 秒話す → 停止 | Take が声トラック末尾に追加され、波形が出る。テイク名「録音 1」 |
| A-2 | 録音中に一時停止 → 10 秒待つ → 再開 → 停止 | 一時停止中の時間は Take に含まれない。ファイルは 1 つ（seg-0001.wav） |
| A-3 | 録音中に「● マーカー」「噛んだ」を押す | 停止後、波形下にマーカーが出て、バナー「マーカー n 件」→「次へ」で移動できる |
| A-4 | Show Assets にジングルを登録し ★ にしてから録音中に「♪ <名前>」を押す | 停止後、素材レイヤーに挿入され、その発言位置に追従している |

| # | 手順 | 期待 |
|---|---|---|
| C-1 | 録音中に**電話を着信**（別の端末からかける）→ 出ずに切る | 「割り込みで録音が止まりました」→ 録音ボタンで再開 → seg-0002.wav が作られ、`⏸` マーカーが打たれる。着信前の音声は残っている |
