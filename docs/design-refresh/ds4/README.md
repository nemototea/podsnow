# Design system 4 の見本（Issue #235）

`mock.html` は、ユーザーと合意した見た目の見本そのもの。**見た目の正はこのファイル**で、
`DESIGN_SYSTEM.md` はここから値と決まりを書き写した記録である（ユーザー判断 2026-10-06）。

- 公開版（非公開の Artifact）: https://claude.ai/artifact/LTuBLC3Vj6t64CaNnf9sov
- ブラウザでそのまま開ける（Google Fonts の Figtree / Noto Sans JP を読み込む）。
- 見本を変えるときは、Artifact とこのファイルの両方を同じ内容にし、`DESIGN_SYSTEM.md` の対応する値も直す。
  食い違いを見つけたら、見本に合わせて文書を直す。見本と文書の規則（コントラストなど）がぶつかるときは、
  勝手にどちらかに寄せず、ユーザーに確かめてから見本を直す。
- 実装はこの見本の再現を目標にする。文書だけを見て見本と違う見た目にしない。
- 整形しない（`.prettierignore`）。公開版と 1 字ずつ比べられるようにするため。

見本に含まれるもの: 5 つの画面（ホーム、番組、収録、編集、書き出し）と編集の構成の帯（4b）・録音前の構成（4c）（Issue #254）、番組 4 つ分のアートワークと
そこから計算した色、ロゴとアプリアイコンの 3 案（A に決定）、黄の色味 3 つ（レモンに決定）。
番組とロゴ案と黄の色味はページ上部で切り替えられる。マリーゴールドとサンフラワー、ロゴ B / C は比べるために残している。
