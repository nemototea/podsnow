PodsNow PN-01ポケットに入る、ひとり放送局

01 ・ 録音タブ 本体色 3 種

録り始める瞬間を、機材を触る体験にする

3 台とも、同じ部品を同じ配置で使っています。変えているのは本体の色と液晶のバックライトだけです。ライトテーマはクリアとイエロー、ダークテーマは夜のスタジオを担当します。

02 ・ 部品表 PARTS

部品ごとの役割

飾りに見える部品も、すべて録音の状態か操作につながっています。意味を持たない装飾は、ビス・パーティングライン・シボの 3 つだけにしました。

  1. 1透明な上ぶたと基板マイクカプセルとコンデンサが見える窓。録音中は基板の LED だけが点く。動きを減らす設定では静止画にする
  2. 2入力ダイヤル押すと入力の選択が開く。つまみの向きで、内蔵マイクか外部入力かが分かる
  3. 3ON AIR ランプ収録中だけ点灯し、点滅はしない。ランプの下に「収録中」の文字を必ず添え、色と文字の両方で伝える
  4. 4モードスイッチ録音・編集・書き出しの 3 タブ。収録中はスライドが止まり、「HOLD」の刻印が出る（§7 の移動抑止）
  5. 5ドット液晶時間、テイク番号、入力、今の話題、レベルを 1 枚にまとめる。ピーク LED はベゼル側に置き、液晶が見にくい屋外でも分かるようにする
  6. 6台本カード話すこと。話し終えた行には手書きの線、今の行には蛍光マーカー。紙を押さえるクリップは、スクロールの取っ手を兼ねる
  7. 7マスキングテープのパッドジングルと効果音。番組の素材名を手書き風に貼る。最後の枠は素材の追加
  8. 8ピアノキー言い直す、一時停止、収録を終える。押すと 4px 沈み、触覚フィードバックが返る。赤いキーは録音と停止だけに使う
  9. 9ビス・シボ・パーティングライン素材感を出すための飾り。本体色ごとに陰影をトークンで持つ
03 ・ ほかの画面 HOME / EDIT / EXPORT

棚、編集機、書き込み

Home はエピソードを MD の棚として並べます。編集はジョグダイヤルのついた編集機として、書き出しはディスクに書き込む場面として描きました。

04 ・ 本体色 SHELL COLORS

着せ替えられる 4 色

本体色は「素材の色」という独立した系統です。録音のコーラルと削除のローズは状態を表す色として取っておき、本体色には使いません。そのため赤い本体は作りません。液晶の色は本体色と組にして決めます。

05 ・ アイコン APP ICON

アイコンは PN-01 の正面

液晶の中に 2 段の全文 Pods / Now. を表示するので、「全文を残す」規則はそのまま守れます。本体色の違いは、iOS の代替アイコンとして選べるようにします。

外向けはネオブルータリズムで組む

07 ・ 実装に向けて NOTES

このまま作るときに決めること

描画

  • ノブのローレット、ジョグ、液晶のドット格子、基板の絵は Skia（@shopify/react-native-skia）で描く案。SVG では、レベル更新のたびに再描画が重くなる【仮説・要計測】
  • キーの押し込みは、今の Button の 2px の押し込みを 4px に広げ、下辺の影の厚みを縮める。boxShadow の inset が RN 0.86 で使えるかは未確認
  • シボ（ノイズ）は 1 枚のタイル画像にし、本体色ごとの濃さはトークンで持つ

書き直す規則

  • §2「ノイズテクスチャ・説明のつかない発光」→ シボと、状態を示すランプ・LED・液晶のバックライトだけを認める
  • §2.1「英字の全部大文字ラベル」→ 本体の刻印（型番・目盛り・HOLD）は飾りとして認める。意味を運ぶ文字は日本語・英語の通常表記で書く
  • §5.5「透過で色を作らない」→ 透明な上ぶたと MD は、背面を固定した不透明な絵として描き、生成時に測る
  • §4 数字の書体 → 液晶の中だけドット書体（DotGothic16、SIL OFL）を使う例外を作る

守ること

  • 収録中の状態は、ランプの色だけで伝えない。液晶の「● REC」とランプ下の「収録中」を必ず添える
  • 手書き風の書体（Yomogi）は、ユーザーが書いた内容（話すこと・素材名・タイトル）だけに使う。UI の文言には使わない
  • 大きい文字の設定では、台本カードとパッドを 1 列にし、液晶の時間を縮める。キーの大きさは変えない
  • 参考画像の製品（ソニー、任天堂など）の形・ロゴの位置・ボタン配置はまねない。借りるのは「成形色・液晶・刻印」という要素だけ

この画面は方向性を検討するための HTML/CSS のモックです。色はトークン生成（ramps.py）を通しておらず、コントラストも測っていません。実機・React Native での描画は未検証です。
